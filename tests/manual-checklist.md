# 手动检查清单

每次较大改动后，在真机（或浏览器的手机模拟模式，宽度 375px）上逐项检查。

## 1. 布局（375px 宽，竖屏）

- [ ] 首页地图：12 座岛两列排列，无横向滚动，底部导航不挡内容
- [ ] 古诗文背诵馆首页、单篇页、遮字背诵三关
- [ ] 答题页：每种题型（单选、多选、判断、字块填空、排序、连线、分栏、断句、默写自查）
- [ ] 每轮结束的总结页
- [ ] 设置页、家长门槛、家长页
- [ ] 刘海屏顶部、底部横条处内容不被遮挡（iPhone 横条机型）
- [ ] 设置里把字号改成“大”，以上页面仍无横向滚动

## 2. 触屏操作

- [ ] 排序题：按住卡片上下拖动可以换位置；点两张卡片可以交换
- [ ] 分栏题：拖动卡片进栏；先点卡片再点栏也行；点栏里的卡片能退回
- [ ] 连线题：点左再点右能配对，点已配对的能拆开
- [ ] 断句题：字与字之间点一下出现“/”，再点消失
- [ ] 遮字背诵：点方块能偷看单个字
- [ ] 单元知识卡：左右滑动能翻卡；滑完马上点“我懂了”能点中（自动测试里模拟触摸时，滑动后第一次点按偶尔不触发，需在真机确认）
- [ ] 田忌赛马模拟器：拖动或点两匹马交换顺序，点“开始比赛”能看到三局结果
- [ ] 起因经过结果：第一步分好栏后能进入第二步选主要内容
- [ ] 六要素点选：点标签再点短文片段能贴上；点已贴的片段能撕下
- [ ] 批注练习：能点选句子、选批注类型
- [ ] 书信拼图：卡片能放进信纸空位，顶格、空两格、右下方的位置看得清楚
- [ ] 拖动卡片时页面不会跟着滚动；不拖卡片时页面能正常上下滚动
- [ ] 所有按钮都容易点中（不小于指尖大小）

## 3. 深色模式

- [ ] 手机切到深色模式：文字清晰可读，按钮、选中、答对答错的颜色能区分
- [ ] 古诗纸页、印章、星星在深色下好看、不刺眼

## 4. 朗读与音效

- [ ] 单篇页“跟我读”：中文朗读、语速较慢，逐句高亮；再点一下能停
- [ ] 离开页面时朗读自动停止
- [ ] 不支持朗读的浏览器（部分微信内置浏览器）：朗读按钮不出现
- [ ] 设置里关掉“朗读”后，朗读按钮不出现
- [ ] 答对、答错、得星有音效；关掉“音效”后安静

## 5. 学习流程（每个单元走一遍）

- [ ] 做题 → 第一次答错：出现提示，可以再试
- [ ] 第二次答错：出现讲解，并加一道同类题（显示“加练一题”）
- [ ] 答错的题进入错题本
- [ ] 重练同一题，连续答对 2 次后移出错题本
- [ ] 闯关测验按正确率得星（≥60% 一星，≥80% 两星，100% 三星），保留最高纪录
- [ ] 每轮结束显示“这几个地方再练练会更棒：……”

## 6. 专项岛、错题本、每日一练、奖励、家长页

- [ ] 句子工坊、字词乐园：按专项练习能进入对应题目
- [ ] 字词乐园：没有生字表时显示“等待家长补录生字表”；补录后出现听写模式，能朗读词语
- [ ] 习作小助手：提纲生成器一步步点选或填写，最后生成提纲卡，能截图
- [ ] 错题本：按岛、按题型筛选；“重练错题”能进入练习
- [ ] 每日一练：10 题、含 2 道古诗文；完成后显示“今天的一练完成啦”，同一天再进来题目相同
- [ ] 奖励：得到新徽章时在总结页有提示
- [ ] 家长页：答对门槛题才能进；导出数据能下载（微信里不能下载时可以复制文本框里的内容）；清空数据要确认两次

## 7. 兼容与离线

- [ ] iOS Safari、安卓 Chrome、微信内置浏览器各打开一次
- [ ] 电脑上直接双击 `index.html` 能用
- [ ] 无痕模式（存储不可用）也能做题，不报错
- [ ] 连续使用 25 分钟出现休息提醒
- [ ] GitHub Pages 打开一次后，关掉网络再打开仍能使用（离线缓存）
- [ ] 手机“添加到主屏幕”后图标、名称正常
- [ ] `dist/yuwen-island.html` 发到手机上能直接打开使用
